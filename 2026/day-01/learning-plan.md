- What is your understanding of DevOps and Cloud Engineering?
Traditionally, Developers would write code and "throw it over the fence" to the ops team to deploy and manage. This created friction, as developers wanted to release new features quickly, while operations teams prioritized stability. DevOps culture removes these barriers by aligning both teams on shared goals 
Core Pillars of DevOpsCulture: 
    - Shared ownership : Foster a collaborative mindset b/w dev and ops 
    - Automation : Replace manual, slow, and error-prone processes with automated scripts and tools
    - Continuous Integration and Continuous Delivery (CI/CD): Developers merge small chunks of code frequently. The code is then automatically built, tested, and prepped for release.
